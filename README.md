# Adeem AI

واجهة ويب شخصية باسم Adeem AI، فيها محادثات وإعدادات شخصية محفوظة محلياً في المتصفح.

## تشغيل المشروع

1. ثبت Node.js على جهاز أو بيئة استضافة تدعمه.
2. شغل `npm install`.
3. أضف متغيرات البيئة التالية في إعدادات السيرفر:
   - `AI_API_KEY`: مفتاح API من مزود نموذج متوافق مع OpenAI Chat Completions.
   - `AI_BASE_URL`: عنوان API الأساسي (الافتراضي Groq).
   - `AI_MODEL`: اسم النموذج المتاح في حسابك.
4. شغل `npm start`.
5. افتح عنوان الموقع.

## تنبيهات مهمة

- الواجهة يمكن تجربتها دون مفتاح، لكن إرسال الرسائل إلى نموذج AI لن يعمل حتى تضيف مفتاح API صالحاً.
- لا تضع مفتاح API داخل `public/app.js` أو أي ملف يراه المتصفح. ضعه فقط في متغيرات بيئة السيرفر.
- الحصة المجانية وحدود النماذج تتغير حسب المزود والحساب والمنطقة؛ تحقق من شروط المزود قبل الاستخدام.
- المحادثات والإعدادات مخزنة في LocalStorage على نفس المتصفح. مسح بيانات المتصفح قد يحذفها.
- هذه نسخة أولية؛ قبل نشرها للعموم أضف تسجيل دخول، تحديد معدل الطلبات، وسياسة خصوصية وحماية مناسبة.
